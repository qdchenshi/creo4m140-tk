Unable to locate a Java Foundation Class (Swing) Installation

The APIWizard was unable to locate a Java Foundation Class (Swing) archive. These classes are required, since the APIWizard user interface components are Java Foundation Class (Swing) elements.

The following options allow you to access the APIWizard through Netscape's Default Java Virtual Machine:

  • Download and install the Java Foundation Class (Swing) archive

    • This is the preferred option. This one-time-only process takes a few minutes to download and configure Swing, but benefits the APIWizard and all other Java-based operations.

      NOTE: This is the only option available to SGI users.

  • Continue, and have Netscape temporarily download the Java Foundation Class (Swing) archive

    • The Java Foundation Class archive is large, and takes time to download. This could result in a start-up time of 45 seconds or more. Also, the archive will not persist between sessions.

      NOTE: This option is not available for SGI users.
