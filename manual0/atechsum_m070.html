Technical Summary of Changes for Creo 4.0 M070
The critical and miscellaneous technical changes in Creo Parametric 4.0 M070 and Creo Parametric TOOLKIT are explained in this section. It also lists the new and superseded functions for this release.
Critical Technical Changes
This section describes the changes in Creo Parametric 4.0 M070 and Creo Parametric TOOLKIT that might require alteration of existing Creo Parametric TOOLKIT, Creo Elements/Pro TOOLKIT, and Pro/TOOLKIT applications.
Updates to Error Code for ProMaterialCurrentGet()
In Creo Parametric 4.0 M070 and later, the function ProMaterialCurrentGet() returns the error type PRO_TK_E_NOT_FOUND. This indicates that material is not set on the part.
