Unable to Locate a Java Foundation Class (Swing) Installation

The APIWizard was unable to locate a Java Foundation Class (Swing) archive. These classes are required, since the APIWizard user interface components are Java Foundation Class (Swing) elements.

The following options allow you to access the APIWizard through Internet Explorer:

  • Download and install Internet Explorer's Java2 Plugin

    • This is the preferred option. Internet Explorer's Java2 Plugin will allow the APIWizard to run in a true Java Runtime Environment. Without the Java2 plugin, The APIWizard search mechanism is very slow.

  • Download and install the Java Foundation Class (Swing) archive

    • This one-time-only process takes a few minutes to download and configure Swing, but benefits the APIWizard and all other Java-based operations. However, The APIWizard Search Mechanism is very slow when running in Internet Explorer's Default Virtual Machine.

  • Continue, and have Internet Explorer temporarily download the Java Foundation Class (Swing) archive

    • The Java Foundation Class archive is large, and takes time to download. This could result in a start-up time of 45 seconds or more. Also, the archive will not persist between sessions, and the APIWizard Search Mechanism is very slow when running in Internet Explorer's Default Virtual Machine.
