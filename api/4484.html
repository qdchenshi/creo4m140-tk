Category Custom user interface, Object ProUIDrawingarea

Function ProUIDrawingareaSizeSet


Description
Set the size of the drawingarea. This field is used only if the parent is a drawing area. If the width or the height parameter is passed a value smaller than the drawingarea's minimum size, the function will fail. The drawingarea's minimum size can be retrieved using ProUIDrawingareaMinimumsizeGet.
Synopsis

The name of the dialog that contains drawingarea.

/* (In)

*/

/* (In)

int height
/* (In)

*/
