Category Custom user interface, Object ProUITable

Function ProUITableMinimumsizeGet


Description
Get the minimum size of the table in pixels. This field is used only if the parent is a drawing area.
Synopsis
#include <ProUITable.h>
ProErrorProUITableMinimumsizeGet(
char* dialog
/* (In)
The name of the dialog that contains the table.
*/
char* component
/* (In)
The name of the table component.
*/
int* min_width
/* (Out)
Minimum width value.
*/
int* min_height
/* (Out)
Minimum height value.
*/
)
Returns
PRO_TK_NO_ERRORThe function succeeded.
PRO_TK_GENERAL_ERRORThe function failed.
PRO_TK_BAD_INPUTSOne or more input arguments was invalid.
