Category Custom user interface, Object ProUITextarea

Function ProUITextareaFocusinActionSet


Description
Sets the focus in action for a text area. This function is called when the user moves the cursor onto the text area using the mouse or [TAB] key.
Synopsis
#include <ProUITextarea.h>
ProErrorProUITextareaFocusinActionSet(
char* dialog
/* (In)
The name of the dialog that contains the text area.
*/
char* component
/* (In)
The name of the text area component
*/
ProUIAction callback
/* (In)
The action to perform when the text area gains user focus.
*/
ProAppData data
/* (In)
Application data to be passed to callback function
*/
)
Returns
PRO_TK_NO_ERRORThe function was successful
PRO_TK_GENERAL_ERRORThe function failed
PRO_TK_BAD_INPUTSAn invalid argument was given
