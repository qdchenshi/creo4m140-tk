Object ProLegacystring

Legacy-encoded multibyte string

Multibyte string in the legacy-encoded format. Legacy encoding refers to the encoding used by Creo Parametric Wildfire 3.0 and earlier. Depending on the language, this encoding is typically some version of an EUC encoding.
