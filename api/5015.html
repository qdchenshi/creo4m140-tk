Category Custom user interface, Object ProUIProgressbar

Function ProUIProgressbarAnchorSet


Description
Sets the position of the progressbar with respect to a given anchor location. This function is applicable only if the parent of the progressbar is a drawing area.
Synopsis
#include <ProUIProgressbar.h>
ProErrorProUIProgressbarAnchorSet(
char* dialog
/* (In)
The name of the dialog that contains the progressbar.
*/
char* component
/* (In)
The name of the progressbar component.
*/
int x
/* (In)
X value with respect to the upper left corner of the parent.
*/
int y
/* (In)
Y value with respect to the upper left corner of the parent.
*/
ProUIAnchor anchor
/* (In)
Location on the progressbar used to set the position.
*/
)
Returns
PRO_TK_NO_ERRORThe function succeeded.
PRO_TK_GENERAL_ERRORThe function failed.
PRO_TK_BAD_INPUTSOne or more input arguments was invalid.
