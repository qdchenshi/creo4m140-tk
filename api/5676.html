Category Custom user interface, Object ProUITree

Function ProUITreeIsCellkeyboardinputEnabled


Description
Checks if the attribute window of the tree respond or not respond to the keyboard input.
Synopsis
#include <ProUITree.h>
ProErrorProUITreeIsCellkeyboardinputEnabled(
char* dialog
/* (In)
The name of the dialog that contains the tree.
*/
char* component
/* (In)
The name of the tree component.
*/
ProBoolean* state
/* (Out)
PRO_B_TRUE when the attribute window respond to the keyboard input; PRO_B_FALSE when the attribute window not respond to the keyboard input.
*/
)
Returns
PRO_TK_NO_ERRORThe function succeeded.
PRO_TK_GENERAL_ERRORThe function failed.
PRO_TK_BAD_INPUTSOne or more input arguments was invalid.
