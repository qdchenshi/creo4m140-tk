Category 3D drawings and annotations, Object ProGtol

Function ProGtolCreate


DEPRECATED: Since Creo 4.0
SUPERSEDED BY: ProMdlGtolCreate
Description
Note: This function is deprecated. Use ProMdlGtolCreate() instead. Creates a gtol by using the description in a gtol data structure. ProAnnotationShow() should be called after creating the gtol in order for the gtol to be displayed.
Synopsis
#include <ProGtol.h>
ProErrorProGtolCreate(
ProGtoldata data
/* (In)
Pointer to the gtol data
*/
ProGtol* gtol
/* (Out)
The new gtol
*/
)
Returns
PRO_TK_NO_ERRORThe function completed successfully.
PRO_TK_BAD_INPUTSThe input argument is invalid.
PRO_TK_GENERAL_ERRORAn error occurred and the function failed.
