Function ProMdlVisibleTextureplacementpropsSet


SUPERSEDED BY: ProMdlVisibleSideTextureplacementpropsSet
Description
Sets the texture placement placement properties of the part, assembly component, subassembly, quilt or surface. These may or may not be visible depending on the properties set by the higher level assembly. Call ProWindowRepaint() after this API to see the changes in UI. Note: Call ProMdlVisibleTexturepropsSet() before this API. This API will be deprecated in future release.
