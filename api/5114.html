Category Custom user interface, Object ProUIRadiogroup

Function ProUIRadiogroupAnchorSet


Description
Sets the position of the radiogroup with respect to a given anchor location. This function is applicable only if the parent of the radiogroup is a drawing area.
Synopsis
#include <ProUIRadiogroup.h>
ProErrorProUIRadiogroupAnchorSet(
char* dialog
/* (In)
The name of the dialog that contains the radiogroup.
*/
char* component
/* (In)
The name of the radiogroup component.
*/
int x
/* (In)
X value with respect to the upper left corner of the parent.
*/
int y
/* (In)
Y value with respect to the upper left corner of the parent.
*/
ProUIAnchor anchor
/* (In)
Location on the radiogroup used to set the position.
*/
)
Returns
PRO_TK_NO_ERRORThe function succeeded.
PRO_TK_GENERAL_ERRORThe function failed.
PRO_TK_BAD_INPUTSOne or more input arguments was invalid.
