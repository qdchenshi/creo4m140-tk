Category Creo Parametric fundamentals, Object ProUnit

Function ProUnitConversionGet


Description
Retrieves the conversion factor for a unit. Works only with basic quantities: PRO_UNITTYPE_LENGTH, PRO_UNITTYPE_MASS, PRO_UNITTYPE_FORCE, PRO_UNITTYPE_TIME, PRO_UNITTYPE_TEMPERATURE, PRO_UNITTYPE_ANGLE.
Replacement in Object TOOLKIT: pfcUnit::ConversionFactor
pfcUnit::ReferenceUnit

)
Returns
PRO_TK_NO_ERRORThe function succeeded.
