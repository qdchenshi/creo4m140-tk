Category Custom user interface, Object ProUIOptionmenu

Function ProUIOptionmenuLabelsSet


Description
Set the labels on the options in an option menu component. The labels are the identifiers for the options in an option menu that are displayed on the dialog. Before defining the labels, you must specify the internal names using ProUIOptionmenuNamesSet().
Synopsis
#include <ProUIOptionmenu.h>
ProErrorProUIOptionmenuLabelsSet(
char* dialog
/* (In)
The name of the dialog that contains the radio group
*/
char* optionmenu
/* (In)
The name of the radio group component
*/
int n_labels
/* (In)
The number in the array of labels
*/
wchar_t** labels
/* (In)
An array of labels, one for each option in the option menu
*/
)
Returns
PRO_TK_NO_ERRORThe function was successful
PRO_TK_GENERAL_ERRORThe function failed
