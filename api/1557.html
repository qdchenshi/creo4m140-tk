Category 3D drawings and annotations, Object ProGtol

Function ProGtolDataGet


DEPRECATED: Since Creo 4.0
SUPERSEDED BY: No successor will be provided.
Description
Note: This function is deprecated. Gets a gtol data description for a specified gtol in a Creo Parametric model. The gtol data structure is workspace copy of the gtol data in the Creo Parametric model; modifying it does not change the gtol in Creo Parametric; use ProGtoldataFree() to free the data after use.
