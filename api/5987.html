Object ProToolkit

Function ProToolkitUnicodeencodingIsEnabled


DEPRECATED: Since Creo 3
SUPERSEDED BY: No successor will be provided.
Description
Identifies if this Creo Parametric TOOLKIT application is running with legacy or Unicode encoding.
Synopsis
#include <ProUtil.h>
ProErrorProToolkitUnicodeencodingIsEnabled(
ProBoolean* unicode_encoding
/* (Out)
PRO_B_TRUE if the application is using Unicode encoding (the default), PRO_B_FALSE if using legacy encoding (due to registry file setting or ProToolkitUnicodeencodingDisable()
*/
)
Returns
PRO_TK_NO_ERRORThe function succeeded.
PRO_TK_BAD_INPUTSOne or more input arguments was invalid.
See Also
ProToolkitUnicodeencodingDisable
