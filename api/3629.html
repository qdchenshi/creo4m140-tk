Category Parameters and relations, Object ProRelation

Function ProRelationEval


DEPRECATED: Since Creo 3
SUPERSEDED BY: ProRelationEvalWithUnits
Description
Note: This function is deprecated. Use ProRelationEvalWithUnits(). Evaluates the supplied right-hand side of a typical expression (lhs = rhs) and returns the value in the form of a parameter value.
Replacement in Object TOOLKIT: pfcRelationOwner::EvaluateExpression

/* (In)

*/
ProParamvalue* p_value
/* (Out)
The evaluated result in the form of a parameter value
*/
)
Returns
PRO_TK_NO_ERRORThe function successfully evaluated the expression.
PRO_TK_GENERAL_ERRORAn error occurred and the function failed.
